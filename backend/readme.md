# Browser Arcade ASP.NET

## Development server

To start a local development server, run:

`dotnet run`

## Hot reload options

To start a server that reacts to changes, add the `watch` flag:

`dotnet watch run`

## Testing

Tests are located in the backend.Tests folder.

To run the xUnit tests, navigate either to the root folder or the backend.Tests folder and run:

`dotnet test`
